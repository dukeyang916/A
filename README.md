# 旅程拼账

面向旅行场景的多人分账与结算工具。解决一群人出去玩，最后算账算不清、谁多花了谁少花了说不清楚的问题。

基于 [uni-app](https://uniapp.dcloud.net.cn/)（Vue 3 + TypeScript）开发，一套代码可编译到微信小程序、H5 和原生 iOS/Android App。v1.0 优先支持微信小程序。

## 核心功能（v1.0）

- 创建行程，添加同行成员（占位昵称 + 随机头像色，无需绑定微信好友关系）
- 记一笔支出：金额、付款人、消费分类（交通/住宿/餐饮/门票/购物/其他）、参与分摊的人
- 四种分摊方式：均摊 / 按比例 / 按份数 / 自定义金额，金额按分计算避免浮点误差
- 自动计算每人余额，并用最少转账笔数算出结算方案（贪心最大债权人/债务人匹配）
- 结算页可逐笔标记"已转"，并生成可保存到相册的结算结果图片，方便分享到群里
- 行程归档/恢复/永久删除，本机数据一键清除

v1.0 数据完全保存在本机（无后端、无云同步），不支持多人实时协作编辑同一行程。

## 后续规划

- v1.1：语音记账、拍照识别小票、AI 对话式记账
- v1.x：多人云端协作编辑、微信支付转账闭环
- v2：目的地人均花费数据沉淀，给后来的旅行者提供预算参考
- v3：真实行程攻略内容付费查看

## 开发

```bash
npm install

# 微信小程序开发模式（输出到 dist/dev/mp-weixin，用微信开发者工具打开该目录）
npm run dev:mp-weixin

# H5 开发模式
npm run dev:h5

# 类型检查
npm run type-check

# 单元测试（核心结算算法）
npm test
```

使用微信小程序前，需要在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序账号，并将 AppID 填入 `src/manifest.json` 的 `mp-weixin.appid` 字段。
