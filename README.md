# 旅程拼账

面向旅行场景的多人分账与结算工具。解决一群人出去玩，最后算账算不清、谁多花了谁少花了说不清楚的问题。

基于 [uni-app](https://uniapp.dcloud.net.cn/)（Vue 3 + TypeScript）开发，一套代码可编译到微信小程序、H5 和原生 iOS/Android App。v1.0 优先支持微信小程序。

## 核心功能（v1.0）

- 创建行程，添加同行成员（占位昵称 + 随机头像色，无需绑定微信好友关系）
- 记一笔支出：金额、付款人、消费分类（交通/住宿/餐饮/门票/购物/其他）、参与分摊的人
- 四种分摊方式：均摊 / 按比例 / 按份数 / 自定义金额，金额按分计算避免浮点误差
- 自动计算每人余额，并用最少转账笔数算出结算方案（贪心最大债权人/债务人匹配）
- 结算页可逐笔标记"已转"，并生成可保存到相册的结算结果图片，方便分享到群里
- 行程归档/恢复/永久删除，本机数据一键清除

v1.0 数据完全保存在本机（无后端、无云同步），不支持多人实时协作编辑同一行程。

## AI 录入（v1.1）

行程详情页"+ 记一笔"现在会弹出选择：手动 / 对话记账 / 拍照记账 / 语音记账。后三种基于微信云开发 + 腾讯云（ASR 语音识别、OCR 文字识别、混元大模型）实现，AI 解析结果只生成可编辑的草稿，需要用户确认（直接保存或先编辑再保存）才会真正记账，不会静默写入。

这部分依赖微信云开发环境和腾讯云密钥，仓库里不包含任何密钥，首次使用前需要手动配置，步骤见 [docs/cloud-setup.md](docs/cloud-setup.md)。没配置的话这三个入口会报错提示，不影响手动记账。

## 多人协作（v1.x）

行程默认只保存在本机，成员管理页的"邀请协作者"可以把某个行程升级成云端共享：生成一个 6 位邀请码，分享给同行的人，对方在首页"加入行程"输入邀请码和自己的名字即可加入，之后这个行程的成员和支出会在云端同步。

同步方式是"进入行程详情页时拉一次云端最新数据"，不是实时协作：两个人同时编辑同一行程，后保存的会覆盖先保存的（按行程整体的更新时间判断，不是逐字段合并）。日常旅行记账很少出现真正同时编辑的情况，这个限制目前没有进一步处理。

跟 AI 录入一样依赖微信云开发环境（不需要腾讯云那三个 AI 服务的密钥），配置步骤见 [docs/cloud-setup.md](docs/cloud-setup.md)。没配置的话"邀请协作者"会报错提示，不影响单机记账。

## 开发

```bash
npm install

# 微信小程序开发模式（输出到 dist/dev/mp-weixin，用微信开发者工具打开该目录）
npm run dev:mp-weixin

# H5 开发模式
npm run dev:h5

# 类型检查
npm run type-check

# 单元测试（核心结算算法）
npm test
```

使用微信小程序前，需要在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序账号，并将 AppID 填入 `src/manifest.json` 的 `mp-weixin.appid` 字段。
