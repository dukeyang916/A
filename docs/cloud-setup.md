# v1.1 / v1.x 云能力配置指南

v1.1 的语音记账 / 拍照识别小票 / 对话式记账，依赖微信云开发 + 腾讯云三个 AI 服务（ASR、OCR、混元大模型）。v1.x 的多人协作（邀请加入、云端同步）只依赖微信云开发本身，不需要腾讯云那三个 AI 服务。两者共用同一个云开发环境，仓库代码里不包含任何密钥/环境 ID，跳过本文档直接编译运行的话，AI 入口和"邀请协作者"都会报错提示未配置。

下面第 1 步两个功能都要做，第 2/3 步只跟 AI 录入有关，第 5 步只跟多人协作有关。

## 1. 开通微信云开发

1. 用小程序管理员账号登录[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，打开本项目编译后的小程序目录（`npm run dev:mp-weixin` 产出的 `dist/dev/mp-weixin`）。
2. 工具顶部菜单「云开发」→ 首次使用会引导开通，选按量计费或有免费额度的套餐都可以。
3. 开通后，云开发控制台顶部能看到环境 ID（形如 `xxx-1a2b3c4d5e`），把它填进 `src/constants/cloud.ts` 的 `CLOUD_ENV_ID`。

## 2. 开通腾讯云 AI 服务（只影响 AI 录入，多人协作不需要）

云函数里调的是腾讯云的服务，跟微信云开发是两个独立的腾讯系产品，要分别开通：

1. 登录[腾讯云控制台](https://console.cloud.tencent.com)（可以和小程序主体账号一致，也可以是公司主账号）。
2. 在控制台顶部搜索框分别搜索并开通：
   - 语音识别（ASR）—— 用到一句话识别 `SentenceRecognition`
   - 文字识别（OCR）—— 用到通用印刷体识别 `GeneralBasicOCR`
   - 混元大模型 —— 用到 `hunyuan-lite` 模型
3. 在[访问管理 CAM 的 API 密钥页](https://console.cloud.tencent.com/cam/capi)创建一个密钥，得到 `SecretId` / `SecretKey`。建议新建一个只授权上述三个服务的子账号密钥，不要直接用主账号密钥。

## 3. 给云函数配置密钥（只影响 AI 录入）

`cloudfunctions/` 下三个 AI 相关函数（`expenseAsr`、`expenseOcr`、`expenseParse`）都通过环境变量读取密钥，不要把密钥写进代码：

1. 微信开发者工具「云开发」控制台 → 云函数 → 选中某个函数 → 配置 → 环境变量，添加：
   - `TENCENTCLOUD_SECRET_ID`
   - `TENCENTCLOUD_SECRET_KEY`
   - `TENCENTCLOUD_REGION`（建议填 `ap-guangzhou`，三个腾讯云服务在这个区域都能用；不填代码里也有这个默认值）
2. 三个函数要分别配置一遍，环境变量是按函数独立生效的。
3. `tripShareCreate` / `tripShareJoin`（多人协作用）不需要配置任何环境变量，跳过这一步。

## 4. 上传部署云函数

1. 微信开发者工具里右键 `cloudfunctions/` 下每一个函数目录（`expenseAsr`、`expenseOcr`、`expenseParse`、`tripShareCreate`、`tripShareJoin`，一共 5 个）→「上传并部署：云端安装依赖」。
2. 等云端按每个函数自己的 `package.json` 装完依赖即可，不需要本地先 `npm install` 这几个云函数目录。
3. 5 个函数都部署一遍。后续这几个函数代码有更新，重新执行这一步同步即可。

## 5. 多人协作的云数据库配置（只影响多人协作）

邀请协作者 / 加入行程 / 云端同步，靠的是云开发的云数据库，需要手动建集合并配置安全规则：

1. 微信开发者工具「云开发」控制台 → 数据库 → 新建集合，名字填 `shared_trips`（必须是这个名字，代码里硬编码的）。如果嫌麻烦，跳过这一步也行——第一次有人点"邀请协作者"时，云函数会用管理员权限自动建出这个集合，但权限设置仍然要手动配，见下一步。
2. 选中 `shared_trips` 集合 → 权限设置 → 自定义安全规则，粘贴：
   ```json
   {
     "read": "auth.openid in doc.memberOpenIds",
     "write": "auth.openid in doc.memberOpenIds"
   }
   ```
   意思是只有 `memberOpenIds` 数组里记录过的人（行程创建者 + 所有已加入的协作者）能读写这份行程数据，其他人即使猜到 `_id` 也读不到。安全规则的具体语法以微信开发者工具当时的控制台提示为准，这里给的是写这篇文档时的语法，如果控制台报规则不合法，对照控制台的语法提示调整一下表达式即可，规则的"意图"不变。
3. 这一步只用做一次，不需要每次代码更新都重新配置（跟第 4 步的云函数部署是两件独立的事）。

## 6. 真机调试注意事项

- 语音记账首次使用会触发系统麦克风权限弹窗，拍照记账会触发相机权限弹窗，对应 `src/manifest.json` 里 `scope.record` / `scope.camera` 的描述文案。
- 微信开发者工具的模拟器不支持真实录音，语音记账要用真机扫码预览调试。
- 如果某个 AI 入口报错"AI 录入功能仅支持微信小程序"，或者"邀请协作者"报错"多人协作功能仅支持微信小程序，且需要先完成云开发配置"，要么是在 H5/App 端预览（这两个功能本身都是小程序专属），要么是 `CLOUD_ENV_ID` 还没填。
- 协作同步是"进入行程详情页时拉一次云端最新数据"，不是实时推送：两个人同时在各自手机上编辑同一个行程，后保存的会覆盖先保存的（以行程整体的更新时间判断，不是逐字段合并）。日常出行记账很少出现真正同时编辑的情况，这个限制目前没有进一步处理。

## 7. 成本提示

- `hunyuan-lite` 是混元里成本最低的模型，三种录入方式共用同一个解析云函数，调用量基本等于"记账次数"，量级不大。
- ASR、OCR 通常都有每月免费额度，超出部分按量计费，具体额度和单价以腾讯云当时的计费页面为准，本文不保证长期准确，开通时注意确认一下。
- 收据 OCR 用的是通用印刷体识别（兜底方案，任何开通了 OCR 的账号都能用，识别准确度一般）。如果后续想换成更精准的票据专用识别，去 OCR 控制台开通对应产品，把 `cloudfunctions/expenseOcr/index.js` 里的 `GeneralBasicOCR` 换成对应 Action 即可，`guessAmount` 的本地兜底逻辑可以保留也可以去掉。
- 云数据库的读写次数通常也有每月免费额度，多人协作场景下调用量约等于"打开行程详情的次数 + 记账次数"，对一个朋友间记账的小工具来说同样量级不大。
